# 한국사 탑 오르기 (복습 게임)

학생들이 각자 노트북으로 접속해 빈칸 문제를 빨리·정확히 맞힐수록 탑을 더 높이 오르는 실시간 복습 게임입니다. 교사는 관리자 화면에서 진행 상황을 보고, 교실 대형 화면에는 관전용 화면을 띄웁니다.

세계사 버전(`review-game/`)과 완전히 독립된 폴더입니다 — 문제 은행과 서버가 따로 돌아가므로 두 게임을 같은 컴퓨터에서 동시에 켜둘 수도 있습니다(포트가 다름: 세계사 8899, 한국사 8898).

## 실행 방법

1. 교사 PC(데스크탑/노트북 모두 가능)와 학생 노트북들이 **같은 와이파이**에 연결되어 있어야 합니다.
2. 교사 PC에서:
   ```
   cd review-game-korea
   python server.py
   ```
3. 콘솔에 아래처럼 접속 주소가 출력됩니다.
   ```
   학생 접속   http://192.168.x.x:8898/play
   관리자 화면 http://192.168.x.x:8898/admin
   대형 화면   http://192.168.x.x:8898/board
   ```
4. 학생들은 `학생 접속` 주소를 각자 노트북 브라우저에 입력 → 이름 입력 → 참여.
5. 교사는 같은 PC에서 `관리자 화면` 주소(또는 `localhost:8898/admin`)를 열어 출제 범위·제한 시간을 정하고 **게임 시작**.
6. 교실 화면(프로젝터/TV)에는 `대형 화면` 주소를 띄워두면 학생들이 탑 오르는 모습이 실시간으로 보입니다.

학생이 하나도 안 보이거나 접속이 안 되면, 학교 와이파이가 **AP 격리(client isolation)**를 쓰고 있을 가능성이 큽니다. 이 경우 기기 간 통신이 막혀 있어 이 방식이 동작하지 않으니 네트워크 담당자에게 확인하거나 다른 네트워크(예: 교사 PC 핫스팟)를 사용해야 합니다.

USB로 다른 컴퓨터에 옮겨서 쓰는 경우, **원본을 수정했다면 USB의 `review-game-korea` 폴더도 다시 덮어써야** 반영됩니다.

## 문제 만들기 / 관리하기

문제는 `review-game-korea/data/questions.txt` 파일에 한 줄씩 저장됩니다.

```
단원(태그) | 문제(빈칸은 ____ 로 표시) | 정답(여러 정답은 / 로 구분)
```

- `#`으로 시작하는 줄과 빈 줄은 무시됩니다.
- 단원 태그는 자유롭게 정하면 됩니다 — 관리자 화면에서 이 태그로 출제 범위를 골라 시작합니다.
- 메모장 등으로 미리 대량 입력해두거나, 수업 중 관리자 화면의 "문제 추가" 폼으로 하나씩 추가할 수도 있습니다.
- 서버가 켜져 있는 동안 파일을 직접 수정했다면, 관리자 화면의 **"문제 다시 불러오기"** 버튼을 눌러야 반영됩니다. 관리자 화면에서 추가한 문제는 즉시 반영됩니다.

## 게임 규칙

- 빠르게(5초 이내) 맞히면 +3층, 10초 이내 +2층, 그보다 늦으면 +1층. 틀리면 그 자리에 머무르고 바로 다음 문제로 넘어갑니다.
- 라운드를 시작하면 전체 학생의 층수/기록이 초기화됩니다.
- 한 라운드 안에서 문제를 다 풀면 같은 범위 안에서 문제가 반복(재출제)됩니다 — 제한 시간(5~10분) 동안 계속 플레이할 수 있게 하기 위함입니다.
- **전체 초기화**를 누르면 참여자 명단 자체가 비워집니다(새 차시를 시작할 때 사용).

## 파일 구성

```
review-game-korea/
  server.py            서버 (외부 패키지 설치 불필요, Python만 있으면 실행)
  data/questions.txt   문제 은행 (직접 편집)
  static/
    play.html          학생 화면
    admin.html         관리자 화면
    board.html         대형 화면(전광판)
```
