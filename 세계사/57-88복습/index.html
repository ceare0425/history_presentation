🏯Ⅲ-1. 아시아의 다민족 제국들
✦   ✦   ✦
Ⅲ — 1
◆

아시아의 다민족 제국들

▸ 청 제국: 강희·옹정·건륭제 / 다민족 통치 / 명·청대 경제·문화
▸ 에도 막부: 센고쿠 시대 / 막번 체제·쇄국·조닌 문화
▸ 무굴 제국: 아크바르·아우랑제브 / 힌두·이슬람 융합
▸ 오스만 제국: 메흐메트·술레이만 / 티마르·데브시르메·밀레트
✦   ✦   ✦
🐉Ⅲ-1 · 청 제국 — 성립과 발전 (57~58쪽)
◆
🐉 청의 성립
  • 누르하치: 팔기제로 여진족 통합 → 후금 건국
  • 홍타이지: 유목 세계 통합, 국호를 청으로 변경
  • 명 멸망 후 중국 대륙으로 진출
👑 황제별 업적
  • 강희제: 삼번의 난 진압, 지정은제, 네르친스크 조약
  • 옹정제: 군기처 설립, 캬흐타 조약
  • 건륭제: 티베트·신장·몽골 정복, 《사고전서》
★ 쇠퇴 원인: 농경지 부족 + 자연재해 + 백련교의 난
🐉Ⅲ-1 · 청 제국 — 다민족 통치·경제·문화 (57~58쪽)
◆
🗺️ 다민족 통치
  • 만주족 고유문화 유지: 만주 문자, 만주 지역 이주 금지
  • 한족 강경책: 변발 강요, 문자의 옥
  • 한족 회유: 만한 병용제, 신사 우대
  • 번부(티베트·신장·몽골): 간접 지배
💰 명·청대 경제·문화
  • 무역: 광저우 일원화, 공행을 통한 무역
  • 창장강 하류: 수공업 중심지 (면직·견직)
  • 문화: 경극, 《홍루몽》, 양명학(지행합일), 고증학(실증)
⛩️Ⅲ-1 · 에도 막부 (59~60쪽)
◆
⚔️ 센고쿠 시대 → 에도 막부
  • 오닌의 난 → 100여 년 센고쿠 시대
  • 오다 노부나가: 조총 전법으로 통일 기반
  • 도요토미 히데요시: 통일 후 조선 침략(임진왜란)
  • 도쿠가와 이에야스: 세키가하라 전투 승리 → 에도 막부
🏯 에도 막부의 발전
  • 막번 체제: 쇼군(직할지) + 다이묘(번)
  • 산킨코타이제: 다이묘의 에도·번 교대 거주
  • 쇄국 정책: 네덜란드만 데지마 교역 허가, 난학 유입
  • 조닌 문화: 조카마치, 가부키, 우키요에
🕌Ⅲ-1 · 무굴 제국의 발전 (61~62쪽)
◆
🕌 무굴 제국 성립과 발전
  • 바부르: 티무르 후손, 델리 술탄 왕조 무너뜨림
  • 아크바르 황제: 종교 관용, 지즈야 폐지, 힌두교도 관리 임명
  • 아우랑제브: 이슬람 제일주의, 지즈야 부활 → 힌두·시크교도 반발
  • 쇠퇴: 마라타 동맹 + 영국·프랑스 침투
🏛️ 문화 — 힌두·이슬람 융합
  • 시크교 성립: 힌두교 + 이슬람교 융합
  • 무굴 회화, 우르두어 사용
  • 타지마할: 샤자한이 왕비 추모로 건축
  • 인도양 무역 주도: 동남아·유럽 연결
🦅Ⅲ-1 · 오스만 제국 — 성립과 발전 (63~64쪽)
◆
🦅 오스만 제국의 발전
  • 메흐메트 2세: 비잔티움 제국 멸망(콘스탄티노폴리스 함락, 1453)
  • 셀림 1세: 맘루크 왕조 멸망, 메카·메디나 보호권 장악
  • 술레이만 1세: 헝가리 정복, 빈 포위, 동지중해 제해권 확보, 법전 편찬
  • 통치: 지방 총독·현지 지배자에게 새 영토 통치 위임
🦅Ⅲ-1 · 오스만 제국 — 통치 제도·티무르·사파비 (63~64쪽)
◆
⚖️ 오스만 통치 제도
  • 티마르 제도: 기병에게 토지 징세권 부여
  • 데브시르메 제도: 크리스트교 청년 징집 → 예니체리
  • 밀레트 제도: 인두세 납부 조건으로 종교 공동체 자치 인정
  • 동서 중계 무역으로 경제 번영
🏰 티무르·사파비 왕조
  • 티무르 왕조: 몽골 제국 재건 내세워 수립 → 오스만인에게 멸망
  • 사파비 왕조: 이스마일 1세 수립
  • 국교: 시아파 이슬람교
  • 아바스 1세 → 이스파한 발전 → 아프간족 침입으로 쇠퇴

시민 혁명과 시민 사회의 형성

▸ 미국 혁명: 보스턴 차 사건 → 독립 선언 → 연방 헌법
▸ 프랑스 혁명: 삼부회 → 인권 선언 → 공포 정치 → 나폴레옹
▸ 빈 체제: 메테르니히 / 7월·2월 혁명 / 차티스트 운동
▸ 민족주의: 이탈리아·독일 통일 / 미국 남북 전쟁
✦   ✦   ✦
🗽Ⅲ-2 · 미국 혁명 (65~66쪽)
◆
🍵 배경과 전개
  • 배경: 7년 전쟁으로 영국 재정 악화 → 식민지 과세
  • 보스턴 차 사건: 동인도 회사 독점에 저항
  • 제2차 대륙 회의: 워싱턴 총사령관 임명
  • 독립 선언문(1776): 천부 인권·국민 주권
📜 결과와 의의
  • 파리 조약(1783): 독립 승인
  • 연방 헌법 제정: 연방주의, 삼권 분립, 공화주의
  • 워싱턴 초대 대통령 선출
  • 한계: 여성·흑인·원주민 권리 제한
★ 과학 혁명 영향: 코페르니쿠스(지동설) → 뉴턴(만유인력) → 계몽사상 발전
⚜️Ⅲ-2 · 프랑스 혁명 (1) — 배경과 전개 (67~68쪽)
◆
⚜️ 혁명의 배경
  • 구제도: 제1·2 신분(세금 면제) ↔ 제3 신분(세금 부담)
  • 왕실 재정 악화: 전쟁·미국 혁명 지원·사치
  • 삼부회 소집: 표결 방식 대립 → 갈등
🏛️ 국민 의회 시기
  • 테니스코트의 서약: 제3 신분이 국민 의회 구성
  • 바스티유 습격 → 봉건적 특권 폐지
  • '인간과 시민의 권리 선언' 발표
  • 새 헌법 제정 후 국민 의회 해산 → 입법 의회
⚜️Ⅲ-2 · 프랑스 혁명 (2) — 과격화와 나폴레옹 (69~70쪽)
◆
🔪 혁명의 과격화
  • 국민 공회: 공화정 선포, 루이 16세 처형
  • 로베스피에르·자코뱅파: 혁명 재판소·공안 위원회 → 공포 정치
  • 테르미도르의 반동: 온건파 쿠데타 → 로베스피에르 처형
  • 총재 정부 → 나폴레옹 쿠데타로 몰락
👑 나폴레옹 시대
  • 나폴레옹: 통령 정부 수립, 《나폴레옹 법전》 편찬
  • 제1 제정: 황제 즉위 → 대륙 패권 장악
  • 대륙 봉쇄령: 유럽과 영국의 무역 금지
  • 러시아 원정 실패 → 워털루 패배 → 몰락
🏛️Ⅲ-2 · 빈 체제와 자유주의 운동 (71~72쪽)
◆
🏛️ 빈 체제와 프랑스
  • 빈 회의: 메테르니히 주도 → 혁명 이전으로 복귀
  • 7월 혁명(1830): 샤를 10세 축출 → 입헌 군주정 수립
  • 2월 혁명(1848): 루이 필리프 축출 → 제2 공화정 → 빈 체제 붕괴
  • 제2 제정: 루이 나폴레옹 황제 즉위
🇬🇧 영국·러시아의 자유주의
  • 영국: 심사법·가톨릭 해방법, 제1차 선거법 개정
  • 차티스트 운동: 〈인민헌장〉, 노동자 참정권 요구
  • 러시아 데카브리스트 봉기(1825): 자유주의 청년 장교 → 실패
  • 브나로드 운동: 지식인의 농민 계몽 운동
🗺️Ⅲ-2 · 민족주의 운동과 국민 국가의 발전 (73~74쪽)
◆
🇮🇹 이탈리아·독일 통일
  • 이탈리아: 재상 카보우르(사르데냐) + 가리발디(의용군) → 이탈리아 왕국(1861)
  • 독일: 프로이센 재상 비스마르크의 철혈 정책
  • 오스트리아 격파 → 북독일 연방 → 프랑스 격파 → 독일 제국(1871)
🇺🇸 미국 남북 전쟁
  • 남부(노예제·자유 무역) ↔ 북부(노예제 폐지·보호 무역)
  • 링컨 대통령 당선 → 남부 7개 주 탈퇴 → 전쟁(1861)
  • 링컨의 노예 해방 선언 → 북부군 승리
  • 이후: 대륙 횡단 철도, 산업 혁명 선도, 자본주의 성장

◆

산업 혁명과 제국주의

▸ 1차 산업 혁명 (영국·증기기관) → 2차 산업 혁명 (전기·석유)
▸ 노동 운동: 러다이트 운동 / 사회주의 (마르크스·엥겔스)
▸ 제국주의 열강의 아프리카·아시아·태평양 분할
✦   ✦   ✦
⚙️Ⅲ-3 · 산업 혁명의 전개 (75~76쪽)
◆
🏭 제1차 산업 혁명 (18세기 후반, 영국)
  • 배경: 명예혁명 후 정치 안정 + 인클로저 운동(노동력) + 지하자원
  • 면직물 공업에서 시작: 방직기·방적기 개발
  • 동력: 와트의 증기 기관
  • 교통 혁명: 증기 기관차(스티븐슨), 증기선(풀턴)
⚡ 제2차 산업 혁명 (19세기 후반)
  • 중심: 독일(제철·화학) + 미국(철강·전기·자동차·석유)
  • 동력: 전기·석유
  • 에디슨·테슬라(전기), 벨(전화)
  • 포드의 대량 생산 체제 → 자동차 대중화
⚙️Ⅲ-3 · 산업 혁명의 영향 — 노동 운동·사회주의 (77~78쪽)
◆
👷 산업 사회와 노동 운동
  • 자본가 계급 + 노동자 계급 등장
  • 러다이트 운동: 기계 파괴 운동 (19세기 초 영국)
  • 차티스트 운동: 참정권 요구
  • 영국 공장법 제정: 장시간 노동·아동 노동 규제
📖 사회주의와 환경 문제
  • 사회주의: 사유재산 비판, 생산 수단 공동 소유

◆
🚢 아편 전쟁·태평천국
  • 제1차 아편 전쟁 결과: 난징 조약 (5개 항구 개항, 홍콩 할양)
  • 태평천국 운동: 홍수전, '멸만흥한', 천조전무 제도(토지 균등)
  • 신사층 향용의 공격으로 붕괴
🔬 양무운동·신해혁명
  • 양무운동: 중체서용론 → 군수 공장·신식 군대 → 청일 전쟁 패배로 한계
  • 변법자강: 캉유웨이·광서제 → 무술변법 → 서 태후 보수파 반발 실패
  • 의화단: '부청멸양' → 8개국 연합군 진압 → 신축조약
  • 신해혁명: 쑨원·삼민주의 → 중화민국 수립
🌸Ⅲ-4 · 일본의 국민 국가 건설 운동 (83~84쪽)
◆
🌸 개항과 메이지 유신
  • 페리 제독 무력시위 → 미일 화친 조약 (시모다·하코다테 개항)
  • 조슈·사쓰마번 주도 → 막부 타도 → 메이지 정부 수립
  • 폐번치현: 번 폐지 → 현 설치 (중앙 집권)
  • 신분제 폐지, 징병제, 자유 민권 운동 → 대일본 제국 헌법
⚔️ 청일·러일 전쟁
  • 운요호 사건 → 강화도 조약(조선 개항)
  • 청일 전쟁: 시모노세키 조약 (배상금·타이완 할양)
  • 러일 전쟁: 포츠머스 조약 (한반도 독점적 지배권, 뤼순·다롄 조차)
