1. 르네상스의 의미

📖 의미
  • 프랑스어로 '부활', '재생'을 의미
  • 14~16세기에 전개된 고대 그리스·로마의 고전 문화를 연구하려는 경향
✦ 특징
  • 인문주의 — 인간의 본성을 적극적으로 탐구하려는 정신 및 이에 대한 학습의 발전
  • 인간을 개성 있는 존재로 파악하고 인간과 자연을 있는 그대로 바라보고 아름다움을 묘사
🗺️ 대표 지역
  • 14세기경 이탈리아에서 시작 → 16세기 알프스 이북 지역으로 확산
🇮🇹 학습지 41쪽 — 2. 이탈리아의 르네상스 > 성립 배경
◆

2. 이탈리아의 르네상스

🌱 성립 배경
  • 유럽 사회의 봉건적 질서 동요, 교회의 권위 쇠퇴
  • 무역을 통해 부를 축적한 유력 상인과 군주들의 문예계 후원
  • 옛 로마 제국 중심지의 고전 문화 전통 보존
🎨 특징
  • 인간과 자연의 사실적인 묘사

3. 알프스 이북의 르네상스

⚡ 특징
  • 배경: 알프스 이북 지역은 봉건 세력과 교회의 영향력이 강하게 남아 있었음
  • 현실 사회와 교회에 대해 비판적, 초기 크리스트교 정신으로 돌아갈 것을 주장
✍️ 에라스뮈스
  • 《우신예찬》
  • 교회·성직자의 타락상 비판
  • → 종교 개혁에 영향
✍️ 토머스 모어
  • 《유토피아》
  • 부조리한 현실 사회 비판
  • 빈부격차 없는 이상 사회 모습 제시

근대 과학기술의 발달

🌱 배경
  • 르네상스 시대의 관찰과 탐구 중시 풍조
🔬 대표적 사례

4. 종교 개혁의 전개 — 루터

✝️ 루터
  • 배경: 교황 레오 10세의 면벌부 판매
  • 전개:
    • 〈95개조 반박문〉 게시 → 면벌부 판매 비판
    • 아우크스부르크 화의에서 루터파 신앙의 자유 인정
✝️ 학습지 42쪽 — 4. 종교 개혁의 전개 > 칼뱅
◆

4. 종교 개혁의 전개 — 칼뱅

✝️ 칼뱅
  • 교리:
    • 예정설 주장 — 인간의 구원은 신에 의해 미리 정해져 있다
    • 검소하고 금욕적 생활 강조
    • 경제적 성공을 신의 은총으로 여김
  • 전파: 신흥 상공업자들의 호응 → 영국, 네덜란드, 프랑스 등으로 확산

4. 종교 개혁의 전개 — 영국

👑 영국 국교회의 성립
  • 배경: 국왕의 이혼 문제로 교황과 갈등
  • 과정:
    • 헨리 8세 — 수장법 선포 (국왕이 교회의 수장)
    • 엘리자베스 1세 — 통일법 반포, 영국 국교회(성공회) 확립

가톨릭 교회의 대응 (반종교 개혁)

⛪ 트리엔트 공의회
  • 16세기 중엽 개최
  • 교황의 권위와 교리 재확인
  • 종교 재판소 설치 → 교회 내부의 결속 강화
✝️ 예수회 창립

📝 학습지 42쪽 — 개념 확인 문제 1 · 괄호 문제
◆

개념 확인 문제 ❶ — 괄호 안의 알맞은 말에 ○표

⑴ 르네상스는 14세기 무렵 ( 이탈리아, 알프스 이북 )에서 먼저 시작되었다.  →  이탈리아
⑵ ( 마키아벨리, 보카치오 )는 《군주론》에서 분열된 이탈리아 통일을 위해 강력한 군주가 필요하다고 주장하였다.  →  마키아벨리
⑶ ( 에라스뮈스, 토머스 모어 )는 《우신예찬》에서 교회와 성직자의 타락상을 풍자하여 종교 개혁에 영향을 주었다.  →  에라스뮈스
📝 학습지 42쪽 — 개념 확인 문제 2 · 빈칸 채우기
◆

개념 확인 문제 ❷ — 빈칸에 알맞은 말을 쓰시오

⑴ 독일의 성직자 루터은/는 〈95개조 반박문〉을 발표하여 면벌부 판매에 대하여 비판하였다.
⑵ 스위스에서는 칼뱅이 인간의 구원은 신에 의해 미리 정해져 있다는 예정설을/를 주장하면서 종교 개혁을 추진하였다.
⑶ 종교 개혁 과정에서 위기를 느낀 로마 가톨릭 교회는 16세기 중엽 트리엔트 공의회를 열어 교황의 권위와 교리를 재확인하였다.
📝 학습지 42쪽 — 개념 확인 문제 3 · 종교 세력 연결
◆

개념 확인 문제 ❸ — 관련 종교 세력을 고르시오

→

→
ㄴ. 칼뱅파
