🏯Ⅲ-1. 아시아의 다민족 제국들
✦   ✦   ✦
Ⅲ — 1
◆

아시아의 다민족 제국들

▸ 청 제국: 팔기제 → 후금 → 청 / 강희·옹정·건륭제 / 다민족 통치
▸ 에도 막부: 센고쿠 시대 / 막번 체제·산킨코타이 / 쇄국·조닌 문화
▸ 무굴 제국: 바부르·아크바르·아우랑제브 / 힌두·이슬람 융합
▸ 오스만 제국: 메흐메트·술레이만 / 티마르·데브시르메·밀레트
▸ 티무르·사파비 왕조
✦   ✦   ✦
🐉Ⅲ-1 · 청 제국 — 성립과 발전 (57~58쪽)
◆
🐉 청의 성립
  • 누르하치: 팔기제로 여진족 통합 → 후금 건국
  • 홍타이지: 유목 세계 통합, 국호를 청으로 변경
  • 명 멸망 후 중국 대륙으로 진출
👑 황제별 업적
  • 강희제: 삼번의 난 진압, 지정은제, 네르친스크 조약
  • 옹정제: 군기처 설립, 캬흐타 조약
  • 건륭제: 티베트·신장·몽골 정복, 《사고전서》 편찬
★ 쇠퇴 원인: 농경지 부족 + 자연재해 + 백련교의 난
🐉Ⅲ-1 · 청 제국 — 다민족 통치·경제·문화 (57~58쪽)
◆
🗺️ 다민족 통치
  • 만주족 고유문화 유지: 만주 문자, 만주 지역 이주 금지
  • 한족 강경책: 변발 강요, 문자의 옥
  • 한족 회유: 만한 병용제, 신사 우대
  • 번부(티베트·신장·몽골): 간접 지배
  • 《대의각미록》: 만주족 통치 정당성 역설
💰 명·청대 경제·문화
  • 무역: 광저우 일원화, 공행을 통한 무역
  • 창장강 하류: 면직·견직 수공업 중심지
  • 문화: 경극, 《홍루몽》 유행
  • 양명학(명대, 지행합일) vs 고증학(청대, 실증)
⛩️Ⅲ-1 · 에도 막부 (59~60쪽)
◆
⚔️ 센고쿠 시대 → 에도 막부
  • 오닌의 난 → 100여 년 센고쿠 시대
  • 오다 노부나가: 조총 전법으로 통일 기반 마련
  • 도요토미 히데요시: 통일 후 임진왜란(조선 침략)
  • 도쿠가와 이에야스: 세키가하라 전투 승리 → 에도 막부
🏯 에도 막부의 발전
  • 막번 체제: 쇼군(직할지) + 다이묘(번)
  • 산킨코타이제: 다이묘의 에도·번 교대 거주 → 통제
  • 쇄국: 데지마에서 네덜란드만 교역, 난학 유입
  • 조닌 문화: 조카마치, 가부키, 우키요에
  • 사상: 국학 운동 → 존왕양이 운동에 영향
🕌Ⅲ-1 · 무굴 제국의 발전 (61~62쪽)
◆
🕌 무굴 제국 성립과 발전
  • 바부르: 티무르 후손, 델리 술탄 왕조 무너뜨리고 무굴 제국 수립
  • 아크바르 황제: 종교 관용, 지즈야 폐지, 힌두교도 관리 임명
  • 아우랑제브: 이슬람 제일주의, 지즈야 부활 → 힌두·시크교도 반발
  • 쇠퇴: 마라타 동맹 + 영국·프랑스 침투
🏛️ 문화 — 힌두·이슬람 융합
  • 시크교 성립: 힌두교 + 이슬람교 요소 융합
  • 무굴 회화 발달, 우르두어 사용
  • 타지마할: 샤자한이 왕비 뭄타즈 마할 추모
  • 인도양 무역 주도: 동남아·유럽 연결
🦅Ⅲ-1 · 오스만 제국·티무르·사파비 왕조 (63~64쪽)
◆
🦅 오스만 제국 성립·통치
  • 메흐메트 2세: 콘스탄티노폴리스 함락(1453) → 비잔티움 제국 멸망
  • 셀림 1세: 맘루크 왕조 멸망, 메카·메디나 보호권
  • 술레이만 1세: 헝가리 정복, 빈 포위, 동지중해 제해권, 법전 편찬
  • 티마르 제도: 기병에게 토지 징세권 부여
  • 데브시르메 제도: 크리스트교 청년 징집 → 예니체리(최정예 부대)
  • 밀레트 제도: 인두세 납부 조건으로 종교 공동체 자치 인정
🏰 티무르·사파비 왕조
  • 티무르 왕조: 몽골 제국 재건 내세워 수립 → 오스만인에게 멸망
  • 사파비 왕조: 이스마일 1세 수립
  • 국교: 시아파 이슬람교
  • 아바스 1세: 이스파한 천도 → 발전
  • 아프간족의 침입 등으로 쇠퇴

시민 혁명과 시민 사회의 형성

▸ 미국 혁명: 과학 혁명·계몽사상 → 보스턴 차 사건 → 독립 선언 → 연방 헌법
▸ 프랑스 혁명: 삼부회 → 인권 선언 → 공포 정치 → 나폴레옹
▸ 빈 체제: 메테르니히 / 7월·2월 혁명 / 차티스트 / 데카브리스트
▸ 민족주의: 이탈리아(카보우르·가리발디) / 독일(비스마르크) / 미국 남북 전쟁
✦   ✦   ✦
🗽Ⅲ-2 · 미국 혁명 (65~66쪽)
◆
🔭 과학 혁명·계몽사상
  • 코페르니쿠스: 태양 중심 지동설
  • 갈릴레이: 망원경 제작, 지동설 입증
  • 뉴턴: 만유인력의 법칙, 기계론적 우주관
  • 계몽사상: 로크·루소의 자연법 사상, 사회 계약설
🦅 미국 혁명
  • 배경: 7년 전쟁 후 영국의 중상주의 정책 강화, 보스턴 차 사건
  • 전개: 독립 선언문 발표(1776) → 파리 조약
  • 결과: 연방 헌법 제정 (연방주의·삼권 분립·공화주의)
  • 워싱턴 초대 대통령 선출
  • 한계: 여성·흑인·원주민 권리 제한, 노예제 유지
⚜️Ⅲ-2 · 프랑스 혁명 (1) — 배경·전개 (67~68쪽)
◆
⚖️ 혁명의 배경
  • 구제도: 제1·2 신분 특권, 제3 신분 세금 부담
  • 왕실 재정 악화: 전쟁·사치 → 루이 16세, 삼부회 소집
  • 갈등: 표결 방식 대립 (제3 신분: 머릿수 표결 주장)
🏛️ 혁명의 전개
  • 국민 의회: 제3 신분 구성, 테니스 코트의 서약
  • 바스티유 습격(1789.7.14.): 혁명 확산
  • 봉건적 특권 폐지 선언
  • 인권선언(인간과 시민의 권리선언): 자유·평등·사유재산 보장
  • 입법 의회: 혁명 전쟁 시작(오스트리아·프로이센 침략)
  • → 파리 민중의 왕궁 습격 → 왕권 정지, 국민 공회 수립
⚜️Ⅲ-2 · 프랑스 혁명 (2) — 과격화·나폴레옹 (69~70쪽)
◆
🔪 혁명의 과격화
  • 국민 공회: 공화정 선포, 루이 16세 처형 → 대프랑스 동맹
  • 로베스피에르·자코뱅파: 혁명 재판소·공안 위원회(공포 정치)
  • 테르미도르의 반동: 온건파 쿠데타 → 로베스피에르 처형
  • 총재 정부: 5명 총재, 식량 부족·물가 상승 해결 부진
👑 나폴레옹 시대
  • 나폴레옹: 쿠데타 → 통령 정부(제1 통령) → 황제 즉위
  • 내정: 프랑스 은행, 《나폴레옹 법전》 편찬
  • 대륙 봉쇄령: 유럽 대륙↔영국 무역 금지
  • 러시아 원정 실패 → 워털루 전투 패배 → 세인트헬레나 유배
  • 의의: 자유주의·민족주의 유럽 확산
🏛️Ⅲ-2 · 빈 체제와 자유주의 운동 (71~72쪽)
◆
🤝 빈 체제 성립·동요
  • 빈 회의: 메테르니히 주도 → 혁명 이전 영토 복귀
  • 자유주의 확산: 이탈리아 카르보나리당, 러시아 데카브리스트 봉기
  • 프랑스 7월 혁명(1830): 샤를 10세 축출 → 7월 왕정
  • 프랑스 2월 혁명(1848): 제2 공화정 수립 → 빈 체제 붕괴
⚡ 영국·러시아의 자유주의
  • 영국: 제1차 선거법 개정, 곡물법·항해법 폐지
  • 차티스트 운동: 《인민헌장》(1838) 발표, 참정권 확대 요구
  • 러시아: 데카브리스트 봉기(1825) 실패 → 전제 정치 강화
  • 크림 전쟁 패배 → 농노 해방령, 지방 의회 설립
  • 브나로드 운동: 지식인들의 농민 계몽 운동
🗺️Ⅲ-2 · 민족주의 운동과 국민 국가의 발전 (73~74쪽)
◆
🇮🇹 이탈리아 통일
  • 재상 카보우르: 사르데냐 중심 내정 개혁
  • 가리발디: 의용군 결성, 이탈리아 남부 점령
  • 1861 이탈리아 왕국 수립
🇩🇪 독일 통일
  • 관세 동맹(1834): 프로이센 주도
  • 재상 비스마르크의 철혈 정책
  • 오스트리아·프랑스 격파
  • 1871 독일 제국 선포
🇺🇸 미국 남북 전쟁
  • 배경: 남부(농장·노예제·자유 무역) vs 북부(상공업·노예제 폐지)
  • 링컨 대통령 당선 → 남부 7개 주 연방 탈퇴
  • 노예 해방 선언(1863)
  • 북부 승리 → 산업화·자본주의 발전

▸ 중국: 아편 전쟁(난징 조약) → 태평천국 → 양무·변법자강 → 의화단 → 신해혁명

▸ 서아시아·아프리카: 탄지마트 → 청년 튀르크당 / 와하브 운동 / 무함마드 알리·아라비 파샤

🐉Ⅲ-4 · 중국의 국민 국가 건설 운동 (81~82쪽)
◆
⚔️ 아편 전쟁·민중 운동
  • 1차 아편 전쟁 → 난징 조약: 5개 항구 개항, 홍콩 할양, 공행 폐지
  • 2차 아편 전쟁 → 톈진·베이징 조약: 추가 개항, 러시아의 연해주 할양
  • 태평천국 운동: 홍수전 '멸만흥한', 천조전무제도 (토지 균등 분배)
  • 신사층 향용의 공격으로 붕괴
🌐 근대화 운동·신해혁명
  • 양무운동: 중체서용론, 군수 공장·신식 군대 → 청일 전쟁 패배로 한계
  • 변법자강 운동: 캉유웨이·량치차오, 무술변법 → 서 태후 보수파 반발로 실패
  • 의화단 운동: '부청멸양', 8개국 연합군 진압 → 신축조약
  • 신해혁명: 쑨원·삼민주의, 우창 신군 봉기 → 중화민국 수립
