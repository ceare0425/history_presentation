개념 확인 문제 1  — 옳으면 ○표, 틀리면 ×표 하시오

⑴ 16세기 초 티무르의 후손 바부르가 아프가니스탄 방면에서 인도 북부로 진출하였으며, 파니파트 전투에서 승리하였다.   ( ○ )
⑵ 아크바르 황제의 사후 마라타 왕국은 마라타 동맹을 결성하여 무굴 제국에 대한 저항을 이어 갔다.   ( × )
※ 마라타 동맹은 아우랑제브 황제 사후에 결성되었다.
⑶ 시크교는 힌두교에서 윤회와 '업' 개념을 받아들였으나, 우상 숭배와 카스트제의 신분 차별을 반대하였다.   ( ○ )
✍️ 학습지 62쪽 — 개념 확인 문제 2 · 빈칸에 알맞은 말을 쓰시오

개념 확인 문제 2  — 빈칸에 알맞은 말을 쓰시오

⑴ 아우랑제브 황제는 ( 이슬람 제일주의 )을/를 바탕으로 힌두교 사원을 파괴하고 지즈야를 부활시켜 힌두교도와 시크교도의 반발을 샀다.
⑵ ( 타지마할 )은/는 무굴 제국의 제5대 황제 샤자한이 왕비인 뭄타즈 마할을 추모하기 위해 세운 묘당으로, 힌두·이슬람 문화의 대표적인 건축물이다.
⑶ 무굴 제국의 공식 문서나 외교문서에는 페르시아어를 사용하였으나, 일상에서는 힌두어에 페르시아어·아랍어가 합쳐진 ( 우르두어 )이/가 널리 사용되었다.

개념 확인 문제 3  — 밑줄 친 '나'에 해당하는 국왕을 쓰고 옳은 설명을 고르시오

"

지금까지 나는 신앙이 다른 사람들을 박해하여 나와 같게 만들려고 하였으며, 그것을 신에 대한 귀의라고 생각하였다. 그러나 지식을 쌓아 감에 따라 나는 후회하는 마음에 사로잡혔다. 강제로 개종시킨 사람에게서 어떻게 성실한 신앙생활을 기대할 수 있을까?

— 무굴 제국 황제의 발언
⑴국왕 밑줄 친 '나'에 해당하는 국왕: ( 아크바르 )
<보기>   ㄱ. 델리 술탄 왕조를 무너뜨리고 무굴 제국을 세웠다.   ㄴ. 비이슬람교도에게 부과한 지즈야를 폐지하였다.  
ㄷ. 구자라트 지역, 벵골 지역을 정복하였다.   ㄹ. 무굴 제국의 영토를 최대로 넓혔다.
⑵설명 옳은 설명: ( ㄴ, ㄷ )
