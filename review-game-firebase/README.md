# 복습 게임 (탑 오르기) - Firebase 버전

`review-game/`, `review-game-korea/`는 **같은 와이파이**에 있어야만 동작하는 로컬 서버 버전입니다.
이 폴더(`review-game-firebase/`)는 그 문제를 해결한 버전으로, Firebase Realtime Database를 통해
**교사와 학생이 서로 다른 네트워크에 있어도** 동작합니다. 서버를 켤 필요도 없이,
아래 주소를 열기만 하면 됩니다.

## 접속 주소

깃허브에 올리면(push) GitHub Pages가 몇 분 안에 자동 반영합니다.

메인 페이지(`https://ceare0425.github.io/history_presentation/review-game-firebase/`)에는
관리자 화면 링크도 있어 교사용입니다. 학생에게는 대신 학생용 페이지
(`https://ceare0425.github.io/history_presentation/review-game-firebase/student.html`,
짧은 주소: **`ceare0425.github.io/h`**)를 공유하세요 — 관리자·대형 화면 링크는 없고,
**학년·반·이름 입력 → 수업 참여/혼자 연습 선택 → 세계사/한국사 선택** 3단계로 들어갑니다.
학년·반·이름은 `localStorage`에 저장되어 두 과목·양쪽 모드에서 계속 재사용되므로, 한 번만
입력하면 다음부터는 바로 모드·과목만 고르면 됩니다. 즐겨찾기 해두면 편합니다.

> ⚠️ **학교 학생 노트북에서는 `tinyurl.com` 단축주소가 유해차단 필터에 막힙니다.**
> 그래서 짧은 주소는 별도 저장소 `ceare0425.github.io`(사이트 최상위)에 리다이렉트로 둡니다:
> - `ceare0425.github.io/h` → 수업참여/혼자연습 메뉴 화면(`student.html`)
> - `ceare0425.github.io/w` → 세계사 수업용(`world/play.html`)
> - `ceare0425.github.io/k` → 한국사 수업용(`korea/play.html`)
>
> 학생에게는 tinyurl 대신 이 주소들을 주세요. (이 폴더가 아니라 `ceare0425/ceare0425.github.io` 저장소에서 수정)

**세계사**
- 학생 접속 (수업용, 선생님이 시작): `https://ceare0425.github.io/history_presentation/review-game-firebase/world/play.html`
  (짧은 주소: `ceare0425.github.io/w` — tinyurl은 학교에서 막힘)
- 혼자 연습 (학생이 직접 범위/시간 정해서 언제든 시작): `https://ceare0425.github.io/history_presentation/review-game-firebase/world/solo.html`
- 관리자 화면: `https://ceare0425.github.io/history_presentation/review-game-firebase/world/admin.html`

**한국사**
- 학생 접속 (수업용, 선생님이 시작): `https://ceare0425.github.io/history_presentation/review-game-firebase/korea/play.html`
  (짧은 주소: `ceare0425.github.io/k` — tinyurl은 학교에서 막힘)
- 혼자 연습 (학생이 직접 범위/시간 정해서 언제든 시작): `https://ceare0425.github.io/history_presentation/review-game-firebase/korea/solo.html`
- 관리자 화면: `https://ceare0425.github.io/history_presentation/review-game-firebase/korea/admin.html`
- 대형 화면: `https://ceare0425.github.io/history_presentation/review-game-firebase/korea/board.html`

짧은 주소(`ceare0425.github.io/h`,`/w`,`/k`)는 별도 저장소 `ceare0425/ceare0425.github.io`의

인터넷이 되는 기기라면 교실 컴퓨터든 학생 노트북이든 어떤 와이파이에 있어도 접속됩니다.

## 사용법 (기존과 동일)

1. 관리자 화면에서 출제 범위(주제)를 고르고 제한 시간을 정한 뒤 **게임 시작**.
2. 학생들은 미리 각자 노트북에서 `.../world/play.html` (또는 `korea/play.html`)을 열고 이름 입력 → 참여.
   선생님이 시작하면 자동으로 문제가 나옵니다.
3. 대형 화면(`board.html`)을 교실 화면에 띄워두면 실시간으로 탑 오르는 모습이 보입니다.
4. 채점 규칙은 그대로입니다: 5초 이내 +3층, 10초 이내 +2층, 그 이후 +1층. 오답은 그 자리에 머무름.

## 아이템전 (관리자 화면 ①의 토글)

수업 게임(개인전)에 재미 요소로 아이템을 켤 수 있습니다. **팀전에서는 동작하지 않습니다.**

- **끄기**: 기존과 동일.
- **난타전 (난투)**: **저격 아이템이 주력**인 난투 모드. **정답을 맞힐 때마다** 아이템 1개.
  - 뽑히는 것의 대부분이 방해 아이템(🌫️안개·🧊얼음·🐌느림보·⬇️미끄럼틀·🥷강탈).
  - 저격 대상은 **상위 3등**(격차 조건 없음). 아래 등수도 상위권을 쏠 수 있고, 상위권끼리도 서로 침. 1·2·3등에 **50/30/20** 가중치로 추첨(1등이 가장 자주 저격당함).
  - 🪞반사경은 **상위 3등 본인에게만** 나오고, 🍵해독·🛟구명조끼도 상위 3등에게 훨씬 자주 나와, 자기가 쏘는 저격은 덜 나옴 — 얻어맞으며 버티는 자리.
  - 피격 후 무적 **1.5초**뿐(연달아 얻어맞음). 방해 효과는 매운맛 수준이지만 🌫️안개·🧊얼음은 **5초**로 짧게, ⬇️미끄럼틀 **-5층**(2등 아래 보호 없이 0층까지)·🥷강탈 **-5층**(나도 +5층).
  - 🎲인생 한방은 **안 나옴**. 하위권에겐 🛋️방구석 축제(혼자 30초 2배)·🎇콤보 스파크(정답마다 카드 뒤집기)·🎫복권·🚀로켓 점프가 훨씬 자주 나와 역전을 돕는다.
- **매운맛**: 자기 강화 + 전체 이벤트 + **선두권 견제**(상위권만 겨냥). **3연속 정답마다** 아이템 1개.
  - ⚡부스터 · 🪜사다리 · 💡힌트 · 🎯골든벨 · 🎫복권 · 🎲인생 한방(하위 50%만) 등 + 🌫️안개·🧊얼음·🐌느림보·⬇️미끄럼틀(-4층)·🥷강탈 + 🪞반사경.

**획득**: 보유는 1개 한도, 쓰기 전엔 새로 안 들어옴. (구버전 '순한맛'은 난타전으로 자동 취급)

**선두권 견제 규칙** — 매운맛 기준 (난타전은 위 설명대로 누구나 저격, 무적 1.5초):
- 대상은 **상위권(15명 이하 3명, 그 이상 20%) 중 랜덤**. 1·2·3위에 **50/30/20** 가중치.
- 그중에서도 **중위권보다 4층 이상 앞선 사람**만 대상. 접전이면 견제가 자기 강화(🪜사다리)로 전환.
- ⬇️미끄럼틀은 **2등 층수 아래로는 안 내려감**. 한 번 맞으면 **8초간 무적**(연타 방지).
- **상위권은 방해 아이템을 못 씀**(좋은 것만 받음). 대형 화면엔 이름 대신 "선두권"으로만 표시.
- 라운드 시작 시 층수와 함께 초기화됩니다.

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(`item_events` 경로 추가됨, 아래 "보안 규칙 설정" 참고).
> 안 해도 게임은 정상이지만 아이템 사용이 서로에게 전달되지 않습니다.

## 혼자 연습하기 (`solo.html`)

수업 시간이 아니어도 학생이 스스로 연습할 수 있는 버전입니다. `play.html`과 달리 선생님이 게임을 시작해줄
필요가 없고, 학생이 직접:

- 연습할 범위(주제)를 하나 이상 고르고
- 제한 시간과 출제 순서(랜덤/순서대로)를 정한 뒤
- **연습 시작** 버튼을 눌러 바로 시작합니다.

문제 은행은 관리자 화면(`admin.html`)에서 선생님만 추가/수정/삭제할 수 있고, `solo.html`은 그 문제를
**읽기만** 합니다 — 학생은 범위 선택과 시작만 할 수 있을 뿐, 문제를 추가하거나 고칠 권한은 없습니다.

연습 진행 자체는 개인 화면 안에서만 돌아가고(다른 학생·`board.html`과 실시간 동기화되지 않음, 수업 점수판에도
안 올라감), 브라우저에 개인 최고 기록(최고 층수)이 저장되어 다시 연습할 때 갱신 여부를 보여줍니다.

### 온라인 연습 학생과 실시간 쪽지 (관리자 화면 "⑤")

학생이 `solo.html`에서 **연습을 시작한 순간부터 끝내거나 창을 닫을 때까지** "온라인"으로 표시됩니다.
관리자 화면 "⑤ 온라인 연습 학생 · 실시간 쪽지" 카드에 학년·반·이름·접속 경과 시간이 실시간으로 뜨고,
**쪽지** 버튼을 누르면 그 학생과 대화창이 열립니다. 보낸 메시지는 학생 화면 상단에 배너로 뜨고,
학생도 화면 상단의 "선생님께 쪽지 보내기" 버튼으로 언제든 먼저 말을 걸 수 있어 관리자 ↔ 학생
양방향 대화가 가능합니다. 학생이 연습 중이 아니거나 창을 닫으면(또는 네트워크가 끊기면) 목록에서
자동으로 사라지지만, 나눈 대화 내용은 계속 남아 있어 다음에 다시 쪽지 버튼을 누르면 이어서 볼 수
있습니다. 카카오톡처럼 **상대방이 확인하면 "1"이 사라지는 읽음 표시**도 있습니다 — 관리자 대화창에서는
선생님이 보낸 말풍선에 학생이 아직 확인 안 했으면 "1"이 붙어 있다가, 학생이 배너를 닫거나 열거나
답장을 보내면(그냥 화면에 잠깐 떴다 사라지는 것만으로는 안 됩니다) 사라집니다. 반대로 학생이 보낸
답장은 선생님이 그 학생과의 대화창을 열어 실제로 볼 때 읽음 처리되어, 학생 쪽 배너에 "선생님이
읽었어요"로 표시됩니다. 또한 선생님이 admin.html을 보고 있지 않을 때 학생이 답장을 보내거나, 학생이
`solo.html`을 다른 화면 보느라 놓쳤을 때를 대비해, **관리자 목록의 쪽지 버튼과 학생 화면의 "선생님께
쪽지 보내기" 버튼 모두에 안 읽은 개수 배지**가 뜨고 확인하면 사라집니다.

> ⚠️ 이 기능도 **보안 규칙을 다시 게시**해야 동작합니다. `firebase-database-rules.json`에
> `presence`·`messages` 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요.

### 혼자 연습 현황 (관리자 화면 "⑥")

학생이 연습 시작 화면에서 **학년·반·이름**을 넣고 연습을 끝내면(제한 시간 종료 시), 그 세션 요약이
`rooms/<room>/solo_log`에 기록됩니다: 학년·반 · 이름 · 시각 · 범위 · 최종 층수 · 정답/오답 수. 반
번호(1~10)는 학년이 달라도 겹칠 수 있어(1학년도 세계사를, 2학년도 한국사를 들을 수 있음) 기록에는
"학년-반" 합친 값이 저장됩니다. 관리자 화면 **"⑥ 혼자 연습 현황"** 카드에서:

- 총 연습 횟수 / 오늘 / 최근 7일 / 연습한 학생 수
- **학생별 표**: 학년/반, 이름, 횟수, 평균 층수, 최고 층수, 최근 연습 시각 (반 순 정렬)
- **최근 세션 목록** (최대 40개): 개별 연습 기록 (학년/반 포함)
- **"기록 비우기"** 버튼으로 solo_log 전체 삭제 (학생 점수·참여 목록과 무관)

**학년·반·이름은 모두 필수**입니다 — 하나라도 비면 "연습 시작"이 눌리지 않습니다. 학년·반은 한 번
고르면 localStorage에 저장돼 다음에도 유지되고(세계사/한국사 공용), 이름은 같은 기기로 `play.html`에
참여한 적이 있으면 자동으로 채워집니다. 문제를 하나도 안 푼 세션은 기록되지 않습니다.

> 이 기능(학년 선택 + `roster`)을 넣기 전에 쌓인 기록은 학년 정보가 없습니다. 당시엔 한국사=1학년,
> 세계사=2학년만 썼으므로 관리자 화면에는 그 학년으로 표시됩니다.

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(아래 "보안 규칙 설정" 참고).
> `firebase-database-rules.json`에 `solo_log` 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요.
> 안 하면 기록이 저장되지 않습니다(연습 자체는 정상 동작).

### 학생 명단 관리 (관리자 화면 "⑦", 명단에 없으면 참여도 연습도 불가)

관리자 화면 "⑦ 학생 명단 관리"에서 **학년·반**을 고르고 학생 이름을 한 줄에 하나씩 등록해두면,
그 학년·반은 `solo.html`(혼자 연습)과 `play.html`(수업 참여) 모두 **명단에 있는 이름만** 입력할
수 있습니다. 오타나 IME 조합 중 깨진 이름(예: 자모가 분리된 이름)으로 기록이 남는 것을 막는
용도이자, 명단에 없는 사람이 아예 들어오지 못하게 막는 용도입니다. "학년-반"은
과목과 무관하게 실제 학급을 가리키는 값이라(같은 1학년 3반이 세계사도 한국사도 듣는 식), 명단은
`solo_log`(혼자 연습 기록)와 달리 방(`rooms/<room>`)별로 나누지 않고 **DB 최상위
`roster/<학년>-<반>`에 딱 하나만** 저장됩니다 — **세계사·한국사 관리자 화면 어느 쪽에서 등록해도
서로 바로 반영됩니다.** **명단을 한 명도 등록하지 않은 학년·반은 제한 없이** 누구나 이름을
입력해 연습할 수 있습니다.

> ⚠️ 이 기능도 **보안 규칙을 다시 게시**해야 동작합니다. `firebase-database-rules.json`에 `roster`
> 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요. 안 하면 명단 저장이 실패하고,
> 혼자 연습은 제한 없이(기존처럼) 동작합니다.

한 줄씩 입력하는 대신, 학교에 이미 있는 **반 명렬표 엑셀 파일을 그대로 업로드**할 수도 있습니다.
파일 하나는 한 학년 기준이므로, 업로드 전에 **몇 학년 명단인지** 먼저 고릅니다:

- 시트가 여러 개면 시트 이름에 들어있는 숫자(예: "1반")를 반 번호로 인식하고, 시트 안의
  "이름"(또는 "성명") 열을 읽습니다.
- 시트가 하나뿐이면 그 안에 "반"(또는 "학급") 열과 "이름"(또는 "성명") 열이 함께 있어야 합니다.
- 업로드 전 몇 개 반에서 몇 명을 찾았는지 확인 창이 뜨고, 확인을 누르면 (선택한 학년의) 그 반들의
  기존 명단을 파일 내용으로 교체합니다(업로드에 없는 다른 반은 그대로 유지).
- 파일 형식이 애매하면 확인 창의 반별 인원 수를 보고 예상과 다르면 취소한 뒤 "명단 양식 다운로드"에
  맞춰 다시 정리하세요. 두 학년을 다 등록하려면 파일을 학년별로 나눠 두 번 업로드하면 됩니다.

### 학생용 시작 화면 (`student.html`)과 자동 참여

`student.html`은 **학년·반·이름 입력 → 수업 참여/혼자 연습 선택 → 세계사/한국사 선택** 3단계
화면입니다. 입력한 학년·반·이름은 `localStorage`(`rg_fb_grade`, `rg_fb_class`, `rg_fb_name`)에
저장되고, `solo.html`·`play.html` 둘 다 이 값을 그대로 읽어 씁니다:

- **`solo.html`**: 학년·반·이름을 이미 알고 있으면 그 입력 UI를 보여주지 않고 "1학년 3반 홍길동
  · 변경" 한 줄 요약으로 접어둡니다. "변경"을 누르면 다시 펼쳐서 고칠 수 있습니다. 학생은 바로
  연습 범위·시간만 고르면 됩니다.
- **`play.html`(수업 참여)**: 학년·반·이름을 이미 알고 있으면 참여 화면을 아예 보여주지 않고,
  명단(roster)을 확인한 뒤 곧바로 대기 화면으로 자동 참여시킵니다. 팀전일 때는 학생이 팀을 직접
  골라야 하므로 자동 참여하지 않고 참여 화면을 보여줍니다. **명단에 없는 이름이면 자동 참여하지
  않고** 참여 화면에 학년·반·이름을 채운 채로 남겨서 직접 확인/수정하게 합니다.

이제 `play.html`도 명단을 확인하므로, 명단이 등록된 학년·반은 명단에 없는 이름으로는 수업 게임에도
참여할 수 없습니다(혼자 연습과 동일한 기준).

`student.html`을 거치지 않고 `ceare0425.github.io/w`, `/k`처럼 과목별 주소로 바로 들어가도
지금까지 저장된 값이 있으면 똑같이 자동으로 처리되고, 없으면(첫 방문) 학년·반·이름을 직접
입력하는 화면이 그대로 나옵니다 — 기존 북마크/QR코드도 그대로 동작합니다.

## 문제 추가하기

관리자 화면(`admin.html`)의 "② 문제 추가"에서:
- 한 문제씩 입력하거나
- "여러 문제 한번에 붙여넣기"를 펼쳐서, 기존 `questions.txt`와 같은 형식(`주제 | 문제 | 정답`)으로
  여러 줄을 붙여넣고 **일괄 추가**를 누르면 바로 반영됩니다. 새로고침/재시작이 필요 없습니다.

기존 `review-game/data/questions.txt` 같은 파일로 대량 등록하고 싶다면(예: 문제를 통째로 다시 넣고 싶을 때):

```
cd review-game-firebase
python tools/import_questions.py ../review-game/data/questions.txt world
python tools/import_questions.py ../review-game-korea/data/questions.txt korea
```

**주의**: 이 스크립트는 해당 방의 문제 전체를 파일 내용으로 덮어씁니다. 관리자 화면에서 추가한 문제가
있다면 먼저 백업하거나, 파일에 그 문제들도 함께 넣어두고 실행하세요.

## 보안 규칙 설정 (한 번만 하면 됨)

Firebase 콘솔은 프로젝트를 처음 만들면 "테스트 모드"로 시작하는데, 이 모드는 30일 후 자동으로
모든 접근을 막아버립니다. 계속 쓰려면 아래 규칙으로 바꿔줘야 합니다.

1. Firebase 콘솔 → Realtime Database → 상단의 **"규칙"** 탭 클릭.
2. 이 폴더의 `firebase-database-rules.json` 내용을 복사해서 붙여넣기.
3. **게시(Publish)** 클릭.

이 규칙은 로그인 없이도 누구나 문제 은행/진행 상황을 읽고 쓸 수 있게 해줍니다(기존 로컬 서버 버전도
같은 와이파이에 있으면 누구나 관리자 화면에 들어갈 수 있었던 것과 동일한 신뢰 수준입니다). 다만
`players` 밑에 쓰는 데이터는 최소한 이름 형식은 지키도록 검증합니다.

## 알아두면 좋은 점 (채점 방식 변경)

기존 로컬 서버 버전은 파이썬 서버가 "몇 초 만에 답했는지"를 직접 재서 채점했습니다. 이 Firebase
버전은 서버가 없기 때문에, 각 학생의 브라우저가 스스로 채점해서 결과만 저장합니다. 복습 게임이라
크게 문제되지는 않지만, 개발자 도구를 다룰 줄 아는 학생이 마음만 먹으면 점수를 조작할 여지는
이론적으로 있습니다.
