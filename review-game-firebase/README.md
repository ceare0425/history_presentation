# 복습 게임 (탑 오르기) - Firebase 버전

`review-game/`, `review-game-korea/`는 **같은 와이파이**에 있어야만 동작하는 로컬 서버 버전입니다.
이 폴더(`review-game-firebase/`)는 그 문제를 해결한 버전으로, Firebase Realtime Database를 통해
**교사와 학생이 서로 다른 네트워크에 있어도** 동작합니다. 서버를 켤 필요도 없이,
아래 주소를 열기만 하면 됩니다.

## 접속 주소

깃허브에 올리면(push) GitHub Pages가 몇 분 안에 자동 반영합니다.

메인 페이지(`https://ceare0425.github.io/history_presentation/review-game-firebase/`)에는
관리자 화면 링크도 있어 교사용입니다. 학생에게는 대신 학생용 페이지
(`https://ceare0425.github.io/history_presentation/review-game-firebase/student.html`,
짧은 주소: **`ceare0425.github.io/h`**)를 공유하세요 — 관리자·대형 화면 링크는 없고,
**학년·반·이름 입력 → 수업 참여/혼자 연습 선택 → 세계사/한국사 선택** 3단계로 들어갑니다.
학년·반·이름은 `localStorage`에 저장되어 두 과목·양쪽 모드에서 계속 재사용되므로, 한 번만
입력하면 다음부터는 바로 모드·과목만 고르면 됩니다. 즐겨찾기 해두면 편합니다.

인터넷이 되는 기기라면 교실 컴퓨터든 학생 노트북이든 어떤 와이파이에 있어도 접속됩니다.

## 사용법 (기존과 동일)

1. 관리자 화면에서 출제 범위(주제)를 고르고 제한 시간을 정한 뒤 **게임 시작**.
2. 학생들은 미리 각자 노트북에서 `.../world/play.html` (또는 `korea/play.html`)을 열고 이름 입력 → 참여.
   선생님이 시작하면 자동으로 문제가 나옵니다.
3. 대형 화면(`board.html`)을 교실 화면에 띄워두면 실시간으로 탑 오르는 모습이 보입니다.
4. 채점 규칙은 그대로입니다: 5초 이내 +3층, 10초 이내 +2층, 그 이후 +1층. 오답은 그 자리에 머무름.

## 아이템전 (관리자 화면 ①의 토글)

수업 게임(개인전)에 재미 요소로 아이템을 켤 수 있습니다. **팀전에서는 동작하지 않습니다.**

- **끄기**: 기존과 동일.
- **난타전 (난투)**: **저격 아이템이 주력**인 난투 모드. **정답을 맞힐 때마다** 아이템 1개.
  - 뽑히는 것의 대부분이 방해 아이템(🌫️안개·🧊얼음·🐌느림보·⬇️미끄럼틀·🥷강탈).
  - 저격 대상은 **상위 3등**(격차 조건 없음). 아래 등수도 상위권을 쏠 수 있고, 상위권끼리도 서로 침. 1·2·3등에 **50/30/20** 가중치로 추첨(1등이 가장 자주 저격당함).
  - 🪞반사경은 **상위 3등 본인에게만** 나오고, 🍵해독·🛟구명조끼도 상위 3등에게 훨씬 자주 나와, 자기가 쏘는 저격은 덜 나옴 — 얻어맞으며 버티는 자리.
  - 피격 후 무적은 맞은 순간부터 시간형 방해 **4초**·즉시형 **2초**(방해가 걸려 있어도 무적이 끝나면 겹쳐 맞음). 방해 효과는 매운맛 수준이지만 🌫️안개·🧊얼음은 **5초**로 짧게, ⬇️미끄럼틀 **-3층**·🥷강탈 **-5층**(나도 +5층).
  - 🎲인생 한방은 **안 나옴**. 하위권에겐 🛋️방구석 축제(혼자 30초 2배)·🎇콤보 스파크(정답마다 카드 뒤집기)·🎫복권·🚀로켓 점프가 훨씬 자주 나와 역전을 돕는다.
- **매운맛**: 자기 강화 + 전체 이벤트 + **선두권 견제**(상위권만 겨냥). **3연속 정답마다** 아이템 1개.
  - ⚡부스터 · 🪜사다리 · 💡힌트 · 🎯골든벨 · 🎫복권 · 🎲인생 한방(하위 50%만) 등 + 🌫️안개·🧊얼음·🐌느림보·⬇️미끄럼틀(-3층)·🥷강탈 + 🪞반사경.

**획득**: 보유는 1개 한도, 쓰기 전엔 새로 안 들어옴. (구버전 '순한맛'은 난타전으로 자동 취급)

**선두권 견제 규칙** — 매운맛 기준 (난타전은 위 설명대로 누구나 저격, 무적 시간형 4초·즉시형 2초):
- 대상은 **상위권(15명 이하 3명, 그 이상 20%) 중 랜덤**. 1·2·3위에 **50/30/20** 가중치.
- 그중에서도 **중위권보다 4층 이상 앞선 사람**만 대상. 접전이면 견제가 자기 강화(🪜사다리)로 전환.
- ⬇️미끄럼틀은 모든 모드 **-3층**. 한 번 맞으면 **2초간 무적**(연타 방지).
- **상위권은 방해 아이템을 못 씀**(좋은 것만 받음). 대형 화면엔 이름 대신 "선두권"으로만 표시.
- 라운드 시작 시 층수와 함께 초기화됩니다.

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(`item_events` 경로 추가됨, 아래 "보안 규칙 설정" 참고).
> 안 해도 게임은 정상이지만 아이템 사용이 서로에게 전달되지 않습니다.

## ⚔️ 라이벌 대결 (관리자 화면 ①의 토글, 개인전 전용)

켜 두면 **게임 시작 때** 직전 판 성적(층수 > 정답 수 > 최고 연속)이 비슷한 학생끼리 1:1 라이벌로 짝지어
`round.rivals`(`{ 학생id: 라이벌id }`)에 저장합니다. 첫 판처럼 성적이 없으면 무작위로 짝짓고, 인원이 홀수면
마지막 한 명은 바로 위 학생을 라이벌로 받습니다(그 학생의 라이벌은 원래 짝 그대로).

- **짝 직접 정하기**: 라이벌 대결을 켜면 관리자 학생 목록에 '라이벌?' 칸이 생겨 팀 변경처럼 A의 라이벌을 B로 고를 수 있습니다(서로 짝이 되고 둘의 원래 짝은 풀림, 게임 중에도 바로 반영). "🎲 라이벌 자동 짝" 버튼으로 한 번에 짝을 지은 뒤 고쳐도 됩니다. 게임 시작 때 짝이 없는 학생만 자동으로 짝지어지고, 정해 둔 짝은 다음 판에도 유지됩니다(라이벌 대결을 끄면 짝이 지워짐).
- 전광판 탑에서는 라이벌끼리 바짝 붙어 서고 짝과 짝 사이는 넓게 벌어집니다(A B · C D · …).
- 학생 화면 위쪽에 "⚔️ 라이벌 ○○ · 2층 앞섬/뒤짐/동점"이 초록·빨강으로 표시되고, 앞서거니 뒤서거니 할 때마다 알림이 뜹니다.
- 종료 화면에 라이벌과의 승패(층수 비교)가 나옵니다.
- **전광판(board.html)** 왼쪽 순위판이 "⚔️ 라이벌 대진표"로 바뀌어 모든 1:1 경기(이름·층수, 앞선 쪽 👑)를 한눈에 보여 주고, 종료 화면에도 경기별 결과가 나옵니다. 관리자 화면 시작 메시지에는 경기 수가 표시됩니다.
- **아이템전과 같이 켜면 방해 아이템은 서로의 라이벌에게만** 날아갑니다(선두권·상위 3등 저격 규칙 대신). 등수와 관계없이 라이벌이 있으면 방해 아이템이 나오고, 라이벌이 없거나(중간 참여) 나갔으면 🪜사다리로 바뀝니다. 아이템 설명·전광판 알림도 "라이벌"로 표시됩니다. 홀수 인원의 남는 한 명은 자기 라이벌을 공격할 수 있지만, 그 라이벌의 공격은 원래 짝에게 갑니다.
- 팀전에서는 동작하지 않고, 게임 도중 들어온 학생이나 라이벌이 나간 학생에게는 표시되지 않습니다.

## 👹 보스 레이드 (관리자 화면 ①의 토글)

반 전체가 힘을 합쳐 보스 한 마리와 싸우는 모드입니다. 한국사는 **헌병 경찰**, 세계사는 **히틀러**가 보스입니다.

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(`raid_hits`·`raid_state` 경로 추가됨, 아래 "보안 규칙 설정" 참고).
> ⚠️ **보스는 전광판(board.html)이 움직입니다.** 레이드 중에는 전광판을 꼭 켜 두세요(전광판이 꺼져 있으면 보스가 멈춤).

- **켜는 법**: 관리자 화면 ①에서 "👹 보스 레이드 → 켜기"를 누르고 난이도(🙂쉬움 · 😐보통 · 😠어려움 · 🔥매우 어려움 · 💀지옥)를 고른 뒤 게임을 시작합니다. 레이드를 켜면 팀전·라이벌·아이템전이 꺼지고 제한 시간은 5분으로 고정됩니다.
- **전광판**: 레이드를 켜면 전광판이 보스 화면(`raid.html`)으로 바뀝니다. 게임을 시작하면 보스가 등장하고, 학생 이름표가 양옆에 나옵니다.
- **학생**: 정답을 맞히면 보스를 공격(빨리 맞힐수록·연속 정답일수록 세게, 5연속마다 치명타), 틀리면 보스가 곧바로 반격합니다. **3연속 정답마다 🛡️ 방패**(최대 2개)를 얻고, 목숨을 잃는 공격(곤봉·오답 반격·호루라기·검문 실패)을 맞으면 방패가 대신 깨집니다(목숨·연속 정답 그대로). 학생 화면 위쪽에 보스 체력과 내 목숨(♥)·방패가 보이고, 쓰러짐·기절·체포 중에는 답을 낼 수 없습니다. 신문 검열을 당하면 문제에 먹칠이 되고, 불심 검문에 걸리면 "○초 안에 정답!" 안내가 뜹니다.
- **보스의 공격**: ⚠ 예고 뒤 곤봉, 오답 반격, 분노(체력 50%) 후 호루라기로 여러 명 기절, 🔗포승줄 체포(반 전체가 정해진 횟수만큼 공격하면 구출), 👮헌병 증원(체력 75%·40%, 헌병이 있는 동안 보스 피해 절반), 📰신문 검열, 📋불심 검문(정답이면 보스 기절), 🚧바리케이드(잠시 공격 차단). 보스는 저절로 회복하지 않고, 체력 60%·30%(광폭화 뒤엔 35초마다)에서 🩹헌병대 지원 요청 회복 의식을 합니다 — 정해진 시간 안에 여러 번 공격하면 차단, 못 끊을 때만 체력을 회복합니다.
- **보스가 노리는 인원**: 전체 학생의 **25%(평소) → 50%(분노, 체력 50% 이하) → 75%(광폭화, 25% 이하)**, 호루라기는 **50%**(예: 20명이면 곤봉 5·10·15명, 호루라기 10명). 난이도는 공격 인원이 아니라 목숨 수·공격 간격·부활 시간·보스 체력으로 조절합니다.
- **인원에 맞춘 조절**: 보스 체력·구출/차단에 필요한 공격 수·검열 인원 등은 30명 기준 값을 참가 인원에 비례해 자동으로 줄이거나 늘립니다.
- **결과**: 보스를 쓰러뜨리거나 시간이 다 되면 라운드가 끝나고, 전광판에 격파/실패 화면과 MVP(피해량 순위), 학생 화면에 결과와 내가 준 피해가 나옵니다.
- **시연·점검**: `raid.html?sim=30`(세계사는 `&boss=world`)을 열면 가짜 학생 30명으로 돌아가는 시연 화면이 나옵니다(Firebase에 연결하지 않음).
- 데이터: 학생 답은 `rooms/{방}/raid_hits`에 쌓이고(학생 → 전광판), 학생별 상태와 보스 상태는 전광판이 `rooms/{방}/raid_state`에 씁니다(전광판 → 학생). 게임 시작·전체 초기화 때 둘 다 비웁니다.

## 🏅 칭호 수집 (`shared/titles.js`)

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(`titles` 경로 추가됨, 아래 "보안 규칙 설정" 참고).
> 안 하면 게임은 정상이지만 칭호가 저장되지 않습니다.

학생은 **학년-반 + 이름**으로 구분되고, 수업 게임(play.html)과 혼자 연습(solo.html) 기록이 합쳐져 `titles/<room>/<학년-반>/<이름>`에 쌓입니다.
처음 접속할 때 기존 `solo_log`·`class_log` 기록을 한 번 옮겨 담으므로(`hist`, `histDone`) 예전에 푼 문제도 반영됩니다.

- **단원 정복**: 주제마다 🥉입문(문제의 30% 맞힘)·🥈숙련(70%)·🥇달인(전부 맞히고 정답률 80% 이상). 칭호 이름은 `titles.js`의 `UNIT_TITLES`(주제 번호 기준).
- **단원 전체(전설)**: 한국사 전 주제 달인 "광복의 증인", 세계사 1단원 "고대 문명 순례자"·2단원 "근세의 설계자"·전체 "세계사 대가".
- **명예(수업 게임)**: 전광판 종료 화면의 정확도왕·번개 정답왕·열공왕·역전왕, 개인전 1등, 라이벌전 승리 횟수로 단계가 오릅니다. **전광판(board.html)이 게임 종료 때 기록**하므로 수업 게임은 전광판을 띄운 채 진행해야 쌓입니다(라운드 token으로 중복 방지).
- **꾸준함**: 문제를 푼 날 3·7·20일.
- **숨은 칭호**: 무결점·극장골·불굴의 의지·올빼미·마라토너(받기 전엔 조건 비공개).
- 학생 화면의 "🏅 칭호 도감"(수업 게임 대기·종료 화면, 혼자 연습 시작·종료 화면)에서 받은 칭호를 누르면 **대표 칭호**가 되고, 수업 게임 중 전광판의 탑·순위판 이름 위에 표시됩니다.
- 한 번 받은 칭호(`seen`)는 문제가 추가돼 조건이 바뀌어도 유지됩니다.

## 혼자 연습하기 (`solo.html`)

수업 시간이 아니어도 학생이 스스로 연습할 수 있는 버전입니다. `play.html`과 달리 선생님이 게임을 시작해줄
필요가 없고, 학생이 직접:

- 연습할 범위(주제)를 하나 이상 고르고
- 제한 시간과 출제 순서(랜덤/순서대로)를 정한 뒤
- **연습 시작** 버튼을 눌러 바로 시작합니다.

문제 은행은 관리자 화면(`admin.html`)에서 선생님만 추가/수정/삭제할 수 있고, `solo.html`은 그 문제를
**읽기만** 합니다 — 학생은 범위 선택과 시작만 할 수 있을 뿐, 문제를 추가하거나 고칠 권한은 없습니다.

연습 진행 자체는 개인 화면 안에서만 돌아가고(다른 학생·`board.html`과 실시간 동기화되지 않음, 수업 점수판에도
안 올라감), 브라우저에 개인 최고 기록(최고 층수)이 저장되어 다시 연습할 때 갱신 여부를 보여줍니다.

**🔁 복습 추천**에는 혼자 연습 기록뿐 아니라 **수업 게임(`play.html`)에서 끝까지 못 맞힌 문제**도 들어갑니다
("수업 게임에서 틀림"으로 표시). 수업 게임이 끝날 때 `class_log`에 `wrong_items`·문제별 마지막 정답 시각을 함께
남기고, 혼자 연습 화면이 같은 학년·반·이름의 기록을 합쳐 계산합니다. 나중에 혼자 연습이나 다른 수업 게임에서
맞히면 목록에서 빠집니다. 정답률·연속 학습일 같은 연습 통계에는 수업 게임 기록을 섞지 않습니다.

### 📖 다시 배우기 / ⭐ 즐겨찾기

문제 화면 상단의 단원 이름 옆에 **"📖 다시 배우기"** 버튼이 뜨면, 그 단원의 실제 프레젠테이션
슬라이드(`pages.json`에 등록된 해당 과목 학습 자료)를 새 탭으로 바로 엽니다 — 연습은 그대로 진행되고
있으니 다시 확인하고 돌아오면 됩니다. `문제 은행의 주제명`과 `pages.json`의 슬라이드 제목이 완전히
같지 않아도(예: "·" vs ",") 느슨하게 매칭하며, 대응하는 슬라이드를 못 찾으면 버튼이 아예 뜨지 않습니다
(세계사는 "01." 같은 차시 번호로 거의 항상 매칭되고, 한능검처럼 번호가 없는 과목은 매칭되지 않을 수
있습니다). 대시보드의 **복습 추천**·**즐겨찾기** 목록에도 같은 버튼이 붙습니다.

문제 화면 상단의 **"☆ 즐겨찾기"** 버튼을 누르면 정답/오답과 무관하게 지금 보이는 문제를 표시해 둘 수
있고(★로 바뀜), 내 학습 기록 대시보드의 **"⭐ 즐겨찾기"** 섹션에 모여 언제든 그 문제들만 모아 다시
풀거나(🔁 복습 추천과 별개) 개별로 해제할 수 있습니다. 학년·반·이름 기준으로 서버(`bookmarks/<room>`)에
저장되므로 같은 정보로 다시 들어오면 기기가 달라도 유지됩니다.

> ⚠️ 즐겨찾기는 **보안 규칙을 다시 게시**해야 동작합니다. `firebase-database-rules.json`에 `bookmarks`
> 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요. 안 해도 연습·"다시 배우기"는 정상
> 동작하고, 즐겨찾기 저장/삭제만 실패합니다.

### 연습 방식: 🏢 탑 오르기 · 👹 보스 레이드 · 🃏 암기 카드 (한국사 `korea/solo.html`)

혼자 연습 시작 화면의 **"연습 방식"**에서 고릅니다(고른 방식·난이도는 그 기기에 기억). 세계사 혼자 연습은 아직 탑 오르기만 있습니다.
복습 추천·즐겨찾기 "다시 풀기"는 늘 탑 오르기로 시작합니다.

- **🏢 탑 오르기**: 기존과 같음.
- **👹 보스 레이드 (혼자)**: 선생님이 게임을 시작하지 않아도 학생 혼자 보스(헌병 경찰)와 싸웁니다. 화면 **왼쪽 반에 보스 화면**
  (`raid.html?solo=1&boss=korea`를 iframe으로), **오른쪽 반에 문제**가 나옵니다(휴대폰 세로 화면은 위 보스·아래 문제).
  - 난이도 4단계(보통·어려움·매우 어려움·지옥), 제한 시간 5분. 맞히면 공격, 틀리면 보스 반격.
  - 혼자이므로 규칙을 바꿨습니다: 보스 공격은 **⚠ 예고 뒤 정해진 시간(보통 10초) 안에 다음 문제를 맞히면 막고**, 틀리거나 시간이
    지나면 맞습니다. 회복 의식·체포는 내 정답 몇 개(보통 2개·1개)로 끊고, 검문 실패는 목숨 1개. **쓰러져도 지지 않고**
    부활 시간만 잃으며, 5분 안에 못 쓰러뜨리면 실패.
  - 난이도 수치는 `raid.html`의 `SOLO_DIFFS`(승률 메모 포함, 실제 코드로 120판씩 측정). 수업용 레이드(`DIFFS`)와 별개입니다.
  - 쪽지 창을 여는 동안은 보스도 멈춥니다. 레이드 칭호(수업 게임용)는 쌓이지 않고, 문제별 정답·오답·칭호(단원 정복 등)는 평소처럼 쌓입니다.
- **🃏 암기 카드**: 시간 제한 없이 문제를 보고 답을 떠올린 뒤 **👀 정답 보기(Space) → ❌ 몰랐어요(왼쪽 버튼·← 키) / ⭕ 알았어요(오른쪽 버튼·→ 키)**.
  몰랐던 카드는 3~5장 뒤에 다시 나오고(최대 3번) **🔁 복습 추천**에 들어갑니다. 스스로 매기는 것이라 정답률·칭호에는 넣지 않으며,
  복습 추천에서 빠지려면 탑 오르기·레이드에서 실제로 맞혀야 합니다. 1분 동안 아무것도 안 누르면 자동 종료.
- 기록(`solo_log`)에 `mode`(raid/card, 없으면 탑 오르기)·`raid_diff`·`raid_result`(win/lose/stop)·`cards_*`가 붙고,
  관리자 화면 ⑥의 "층수·결과" 칸에 `👹 보통 격파`, `🃏 카드 12장 · 몰랐음 2`처럼 표시됩니다(평균 층수에서 암기 카드는 제외).

### 온라인 연습 학생과 실시간 쪽지 (관리자 화면 "⑤")

학생이 `solo.html`에서 **연습을 시작한 순간부터 끝내거나 창을 닫을 때까지** "온라인"으로 표시됩니다.
관리자 화면 "⑤ 온라인 연습 학생 · 실시간 쪽지" 카드에 학년·반·이름·접속 경과 시간이 실시간으로 뜨고,
**쪽지** 버튼을 누르면 그 학생과의 대화창이 열립니다. 학생 쪽도 상단의 **"💬쪽지" 버튼**을 누르면
관리자와 똑같은 형태의 **대화창(전체 대화 내역이 말풍선으로 쌓이는 채팅창)**이 뜨고, 그 안에서
바로 답장하거나 먼저 선생님께 말을 걸 수 있어 관리자 ↔ 학생 양방향 대화가 가능합니다. 쪽지가 와도
관리자 쪽처럼 화면에 바로 튀어나오지 않고 "💬쪽지" 버튼에 **안 읽은 개수 배지**만 뜨며, 학생이
버튼을 눌러 대화창을 열어야 내용이 보입니다. 학생이 쪽지를 못 보고 연습을 끝내거나 시간이 다 되면,
**연습 종료 화면 위에 팝업**으로 놓친 쪽지를 띄워 그 자리에서 바로 답장하거나 확인 처리할 수
있습니다. 학생이 연습 중이 아니거나 창을 닫으면(또는 네트워크가 끊기면) 온라인 목록에서 자동으로
사라지지만, 나눈 대화 내용은 계속 남아 있어 다음에 다시 쪽지 버튼을 누르면 이어서 볼 수 있습니다.
카카오톡처럼 **상대방이 확인하면 "1"이 사라지는 읽음 표시**도 있습니다 — 서로의 대화창에서 자신이
보낸 말풍선에 상대가 아직 확인 안 했으면 "1"이 붙어 있다가, 상대가 그 대화창을 열어보는 순간(또는
학생이 놓쳐서 종료 팝업으로 확인/답장하는 순간) 사라집니다.

**🔔 쪽지 알림**: ⑤ 카드 오른쪽 위의 "🔕 쪽지 알림 꺼짐" 버튼을 눌러 켜면, 학생 쪽지가 올 때
"띵" 소리 + 윈도우 알림 팝업(누르면 그 학생 대화창이 바로 열림) + 탭 제목 "(N) 💬 새 쪽지"(다른 탭에
있으면 깜빡임)로 알려 줍니다. 처음 켤 때 브라우저가 알림 허용을 물으면 **허용**을 누르세요. 설정은
브라우저에 기억되어 다음에도 켜진 상태로 열립니다(새로고침 뒤에는 화면을 한 번 클릭해야 소리가 납니다).
관리자 화면이 열려 있는 동안만 동작합니다(최소화·다른 탭은 괜찮음, 탭을 닫으면 알림 없음).

> ⚠️ 이 기능도 **보안 규칙을 다시 게시**해야 동작합니다. `firebase-database-rules.json`에
> `presence`·`messages` 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요.

### 혼자 연습 현황 (관리자 화면 "⑥")

학생이 연습 시작 화면에서 **학년·반·이름**을 넣고 연습을 끝내면(제한 시간 종료 시), 그 세션 요약이
`rooms/<room>/solo_log`에 기록됩니다: 학년·반 · 이름 · 시각 · 범위 · 최종 층수 · 정답/오답 수. 반
번호(1~10)는 학년이 달라도 겹칠 수 있어(1학년도 세계사를, 2학년도 한국사를 들을 수 있음) 기록에는
"학년-반" 합친 값이 저장됩니다. 관리자 화면 **"⑥ 혼자 연습 현황"** 카드에서:

- 총 연습 횟수 / 오늘 / 최근 7일 / 연습한 학생 수
- **학생별 표**: 학년/반, 이름, 횟수, 평균 층수, 최고 층수, 최근 연습 시각 (반 순 정렬)
- **최근 세션 목록** (최대 40개): 개별 연습 기록 (학년/반 포함)
- **"기록 비우기"** 버튼으로 solo_log 전체 삭제 (학생 점수·참여 목록과 무관)

**학년·반·이름은 모두 필수**입니다 — 하나라도 비면 "연습 시작"이 눌리지 않습니다. 학년·반은 한 번
고르면 localStorage에 저장돼 다음에도 유지되고(세계사/한국사 공용), 이름은 같은 기기로 `play.html`에
참여한 적이 있으면 자동으로 채워집니다. 문제를 하나도 안 푼 세션은 기록되지 않습니다.

> 이 기능(학년 선택 + `roster`)을 넣기 전에 쌓인 기록은 학년 정보가 없습니다. 당시엔 한국사=1학년,
> 세계사=2학년만 썼으므로 관리자 화면에는 그 학년으로 표시됩니다.

> ⚠️ 이 기능을 쓰려면 **보안 규칙을 다시 게시**해야 합니다(아래 "보안 규칙 설정" 참고).
> `firebase-database-rules.json`에 `solo_log` 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요.
> 안 하면 기록이 저장되지 않습니다(연습 자체는 정상 동작).

### 학생 명단 관리 (관리자 화면 "⑦", 명단에 없으면 참여도 연습도 불가)

관리자 화면 "⑦ 학생 명단 관리"에서 **학년·반**을 고르고 학생 이름을 한 줄에 하나씩 등록해두면,
그 학년·반은 `solo.html`(혼자 연습)과 `play.html`(수업 참여) 모두 **명단에 있는 이름만** 입력할
수 있습니다. 오타나 IME 조합 중 깨진 이름(예: 자모가 분리된 이름)으로 기록이 남는 것을 막는
용도이자, 명단에 없는 사람이 아예 들어오지 못하게 막는 용도입니다. "학년-반"은
과목과 무관하게 실제 학급을 가리키는 값이라(같은 1학년 3반이 세계사도 한국사도 듣는 식), 명단은
`solo_log`(혼자 연습 기록)와 달리 방(`rooms/<room>`)별로 나누지 않고 **DB 최상위
`roster/<학년>-<반>`에 딱 하나만** 저장됩니다 — **세계사·한국사 관리자 화면 어느 쪽에서 등록해도
서로 바로 반영됩니다.** **명단을 한 명도 등록하지 않은 학년·반은 제한 없이** 누구나 이름을
입력해 연습할 수 있습니다.

> ⚠️ 이 기능도 **보안 규칙을 다시 게시**해야 동작합니다. `firebase-database-rules.json`에 `roster`
> 경로가 추가되어 있으니, 콘솔 규칙 탭에 다시 붙여넣고 게시하세요. 안 하면 명단 저장이 실패하고,
> 혼자 연습은 제한 없이(기존처럼) 동작합니다.

한 줄씩 입력하는 대신, 학교에 이미 있는 **반 명렬표 엑셀 파일을 그대로 업로드**할 수도 있습니다.
파일 하나는 한 학년 기준이므로, 업로드 전에 **몇 학년 명단인지** 먼저 고릅니다:

- 시트가 여러 개면 시트 이름에 들어있는 숫자(예: "1반")를 반 번호로 인식하고, 시트 안의
  "이름"(또는 "성명") 열을 읽습니다.
- 시트가 하나뿐이면 그 안에 "반"(또는 "학급") 열과 "이름"(또는 "성명") 열이 함께 있어야 합니다.
- 업로드 전 몇 개 반에서 몇 명을 찾았는지 확인 창이 뜨고, 확인을 누르면 (선택한 학년의) 그 반들의
  기존 명단을 파일 내용으로 교체합니다(업로드에 없는 다른 반은 그대로 유지).
- 파일 형식이 애매하면 확인 창의 반별 인원 수를 보고 예상과 다르면 취소한 뒤 "명단 양식 다운로드"에
  맞춰 다시 정리하세요. 두 학년을 다 등록하려면 파일을 학년별로 나눠 두 번 업로드하면 됩니다.

### 학생용 시작 화면 (`student.html`)과 자동 참여

`student.html`은 **학년·반·이름 입력 → 수업 참여/혼자 연습 선택 → 세계사/한국사(혼자 연습이면 한능검 기출 풀기도) 선택** 3단계
화면입니다. 입력한 학년·반·이름은 `localStorage`(`rg_fb_grade`, `rg_fb_class`, `rg_fb_name`)에
저장되고, `solo.html`·`play.html` 둘 다 이 값을 그대로 읽어 씁니다:

- **`solo.html`**: 학년·반·이름을 이미 알고 있으면 그 입력 UI를 보여주지 않고 "1학년 3반 홍길동
  · 변경" 한 줄 요약으로 접어둡니다. "변경"을 누르면 다시 펼쳐서 고칠 수 있습니다. 학생은 바로
  연습 범위·시간만 고르면 됩니다.
- **`play.html`(수업 참여)**: 학년·반·이름을 이미 알고 있으면 참여 화면을 아예 보여주지 않고,
  명단(roster)을 확인한 뒤 곧바로 대기 화면으로 자동 참여시킵니다. 팀전일 때는 학생이 팀을 직접
  골라야 하므로 자동 참여하지 않고 참여 화면을 보여줍니다. **명단에 없는 이름이면 자동 참여하지
  않고** 참여 화면에 학년·반·이름을 채운 채로 남겨서 직접 확인/수정하게 합니다.

이제 `play.html`도 명단을 확인하므로, 명단이 등록된 학년·반은 명단에 없는 이름으로는 수업 게임에도
참여할 수 없습니다(혼자 연습과 동일한 기준).

`student.html`을 거치지 않고 `ceare0425.github.io/w`, `/k`처럼 과목별 주소로 바로 들어가도
지금까지 저장된 값이 있으면 똑같이 자동으로 처리되고, 없으면(첫 방문) 학년·반·이름을 직접
입력하는 화면이 그대로 나옵니다 — 기존 북마크/QR코드도 그대로 동작합니다.

## 문제 추가하기

관리자 화면(`admin.html`)의 "② 문제 추가"에서:
- 한 문제씩 입력하거나
- "여러 문제 한번에 붙여넣기"를 펼쳐서, 기존 `questions.txt`와 같은 형식(`주제 | 문제 | 정답`)으로
  여러 줄을 붙여넣고 **일괄 추가**를 누르면 바로 반영됩니다. 새로고침/재시작이 필요 없습니다.

기존 `review-game/data/questions.txt` 같은 파일로 대량 등록하고 싶다면(예: 문제를 통째로 다시 넣고 싶을 때):

```
cd review-game-firebase
python tools/import_questions.py ../review-game/data/questions.txt world
python tools/import_questions.py ../review-game-korea/data/questions.txt korea
```

**주의**: 이 스크립트는 해당 방의 문제 전체를 파일 내용으로 덮어씁니다. 관리자 화면에서 추가한 문제가
있다면 먼저 백업하거나, 파일에 그 문제들도 함께 넣어두고 실행하세요.

## 보안 규칙 설정 (한 번만 하면 됨)

Firebase 콘솔은 프로젝트를 처음 만들면 "테스트 모드"로 시작하는데, 이 모드는 30일 후 자동으로
모든 접근을 막아버립니다. 계속 쓰려면 아래 규칙으로 바꿔줘야 합니다.

1. Firebase 콘솔 → Realtime Database → 상단의 **"규칙"** 탭 클릭.
2. 이 폴더의 `firebase-database-rules.json` 내용을 복사해서 붙여넣기.
3. **게시(Publish)** 클릭.

이 규칙은 로그인 없이도 누구나 문제 은행/진행 상황을 읽고 쓸 수 있게 해줍니다(기존 로컬 서버 버전도
같은 와이파이에 있으면 누구나 관리자 화면에 들어갈 수 있었던 것과 동일한 신뢰 수준입니다). 다만
`players` 밑에 쓰는 데이터는 최소한 이름 형식은 지키도록 검증합니다.

## 알아두면 좋은 점 (채점 방식 변경)

기존 로컬 서버 버전은 파이썬 서버가 "몇 초 만에 답했는지"를 직접 재서 채점했습니다. 이 Firebase
버전은 서버가 없기 때문에, 각 학생의 브라우저가 스스로 채점해서 결과만 저장합니다. 복습 게임이라
크게 문제되지는 않지만, 개발자 도구를 다룰 줄 아는 학생이 마음만 먹으면 점수를 조작할 여지는
이론적으로 있습니다.
